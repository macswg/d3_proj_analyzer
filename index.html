disguise project snapshot extractor

Drop a Designer .d3 project archive to get the same snapshot JSON the susan_summary plugin captures: transports, setlists, tracks, layers, cues, media and timecode. You don't need Designer. Load the result into d3_snapshot_diff to compare it with another snapshot. Your project stays on this computer: it's read in this browser tab and never uploaded.

What's in it

Transports

Not in a .d3 archive

  • Option switches: options.bin and machine.bin aren't packed into archives, so they're recorded as unknown and the diff tool will say it couldn't compare them.
  • Some build details: the Designer version, revision, branch and build id are included. Licence type, custom release name, RenderStream version and the release flags are left empty, so they show as changed when you compare against a plugin capture.
  • Capture time: set to when the archive file was last modified.
